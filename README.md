📰 MERN Blog Assessment – File-Based Routed Blog
This is a minimal blog platform built using the MERN stack (MongoDB, Express, React, Node.js) as part of a 6-hour technical assessment. The frontend implements manual file-based routing without any third-party libraries like React Router.

📋 Features
• List all blog posts (Home)
• View a single post by ID
• Create a new blog post via form
• Manual, file-based routing
• MongoDB persistence
• RESTful API using Express

🕑 6-Hour Timebox Note
The entire application — frontend, backend, routing, API, and basic styling — was completed within a 6-hour time limit, as instructed in the assessment guidelines.
All commits are within the time window and pushed to this repository for review.

⚙️ Tech Stack
• Frontend: React (Vite), manual file-based routing, CSS
• Backend: Node.js, Express.js
• Database: MongoDB Atlas (Mongoose ODM)
• Version Control: Git + GitHub

🧪 Setup & Running Locally

🔧 Backend (Express + MongoDB)
cd server
npm install
npm run dev
This will start the backend at:
http://localhost:5000

📄 Environment Variables
Create a .env file inside the /server folder with:
PORT=5000
MONGODB_URI=mongodb+srv://subhan:subhan123@cluster0.mongodb.net/blog?retryWrites=true&w=majority

🌐 Frontend (React + Vite)
cd client
npm install
npm run dev
This will start the frontend at:
http://localhost:5173
